# Hilda Asteroid Dynamical Stability Catalogue

This repository contains the dynamical stability catalogue of 2,699 numbered Hilda asteroids studied in Chavez et al. (2026).

The catalogue was produced from 1 Gyr N-body simulations, perfermed using the Mercury Hybrid integrator, including the gravitational influence of the Sun and the four giant planets: Jupiter, Saturn, Uranus, and Neptune.

For each asteroid, 243 test particles were generated by varying five orbital elements (a, e, i, ω, Ω) within their one-sigma uncertainties, resulting in a total of 655,857 test particles.

## Associated Publication

Chavez et al. (2026).

*On the Long-Term Orbital Behaviour of Hilda Asteroids – I. Global Stability Patterns and Catalogue.*

Monthly Notices of the Royal Astronomical Society (MNRAS).

**DOI:** https://doi.org/10.1093/mnras/stag1832

## Catalogue

**File:** `PAPER2_hildas_catalogue.tsv`

The catalogue contains 2,699 records in tab-separated values (TSV) format.

| Column | Description |
|---|---|
| ID | Numbered asteroid identifier |
| Group | Dynamical stability group (I–V) |
| N10Myr | Number of surviving clones after 10 Myr |
| N100Myr | Number of surviving clones after 100 Myr |
| N1Gyr | Number of surviving clones after 1 Gyr |
| T_half_yr | Estimated dynamical half-life, in years |

## Dynamical Stability Groups

The population was classified into five groups according to the survival of the simulated clones over 1 Gyr.

| Group | Classification | Number of asteroids |
|---|---|---:|
| I | Strongly Stable | 1,475 |
| II | Stable | 408 |
| III | Moderately Stable | 327 |
| IV | Weakly Stable | 309 |
| V | Unstable | 180 |
| **Total** | | **2,699** |

Group I contains asteroids for which all 243 clones survived the full integration.

## Interpretation of Dynamical Half-Lives

The column `T_half_yr` provides an estimated dynamical half-life expressed in years.

Values exceeding 1 Gyr represent extrapolated estimates rather than directly observed half-lives within the integration interval.

The symbol `∞` is used for Group I asteroids, whose 243 clones survived the entire 1 Gyr simulation. This notation does not imply infinite physical or orbital stability.

The catalogue describes dynamical stability under the gravitational model adopted in the associated publication and should not be interpreted as a direct measurement of asteroid ages.
